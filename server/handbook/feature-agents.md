# AI and integrations

Put agents to work, ask questions about the project and see what CI says — all without leaving the dashboard. The sidebar groups this under **AI** and **Integrations**; the [AI overview](polier:ai-overview) explains how the pieces fit.

| View | In short | Guide |
|---|---|---|
| **Assistant** | ask the project; apply proposals after confirming | [Assistant](polier:assistant) |
| **Agents** | profiles with role, model, instructions, skills, connectors; assign to tasks | [Agents](polier:agents) |
| **Sessions** | every headless run: transcript, tokens, stop | [Run agents headless](polier:agent-sessions) |
| **Skills** | reusable instructions in `.claude/skills/` | [Skills](polier:skills) |
| **MCP** | Polier as an MCP server, and connectors for sessions | [MCP server](polier:mcp-server), [Connectors](polier:mcp-connectors) |
| **Automations** | rules that suggest actions, dry run only | [Automations](polier:automations) |
| **GitHub** | account connection, pull requests and CI mapped to tasks | [GitHub integration](polier:github-integration) |
