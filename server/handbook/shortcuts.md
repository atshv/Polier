# Keyboard shortcuts

Work without the mouse. Shortcuts are ignored while you type in a field, except `Esc`.

| Keys | Action |
|---|---|
| `Ctrl` / `Cmd` + `K` | open the command palette: views, tasks and quick actions |
| `/` | focus the task search |
| `g` | open the dependency graph |
| `?` | show the shortcut list |
| `Esc` | close the drawer or a dialog, leave selection mode, clear the search |
| `↑` `↓` `Enter` | move and run in the command palette |
| `Enter` / `Space` | open the focused card or row |

## Command palette actions

- **New task** — opens the Plan editor with an empty task
- **New intake proposal**
- **Ask the assistant**
- **Run automations dry run**
- **Refresh everything**
- **Open Settings**

Type part of a task ID or title to jump straight to it.
