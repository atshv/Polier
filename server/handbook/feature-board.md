# Board and Table

The board is where work happens. Both views show the same tasks with the same filters; pick the one that suits the question.

## Board

- **Stage strip** — every stage with done/total, a progress bar and what it waits for (owner decision, open exit gates).
- **Columns** — Pending, In progress, Reviewing, Rework, Blocked, Failed and Done. Empty Rework/Blocked/Failed columns fold into slim rails; Done stays folded until you open it.
- **Cards** — ID, title, labels, stage, owner, and one line with gates, effort and tokens when there is something to show. A claimed task carries a *claimed* badge.

## Table

One row per task with labels, status, stage, owner, gates, effort, tokens, attempts, dependencies and package. Click a row to open the task.

## The toolbar

| Control | Does |
|---|---|
| **View** | switch between built-in and saved views |
| **Group** | group by status, stage, owner, package or label |
| **Sort** + ↑/↓ | order inside each group |
| **+ Filter** | add a condition |
| **Save view** | appears when the setup differs from the default |
| **Select** | turn on bulk actions |
| ≡ | comfortable or compact density |

See [Organise work](polier:organise-work) for filters, views and bulk actions in detail.
