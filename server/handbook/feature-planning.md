# Planning views

Five views show the plan from different angles. All of them are derived from the board and the run records; nothing extra to maintain.

## Plan editor

Create, edit and delete tasks; change dependencies, scopes, gates and stage decisions; reorder stages. Every change is validated and written atomically. For a project without a board, this is where the interview lives.

## Timeline

Tasks on a time axis inside stage lanes, scheduled from dependencies and estimates, with the critical path, today line, fixed dates and overdue markers. See [Plan in time](polier:plan-in-time).

## Cycles

Each stage as a cycle: goal, exit criteria, exit gates, progress, effort, a burndown and the owner decision, which you can set right there.

## Dependencies

The task graph: columns are dependency depth, rows are grouped by stage, colours are statuses. **Fit** scales it to the window, **−** and **+** zoom. Board filters apply here too.

## Dispatch

What may start now (the next wave), what is running, what is blocked and why — with the command that unblocks it — and scope conflicts between tasks that would touch the same files.
