# Your Work and the inbox

**Your Work** answers one question: what needs me now?

## Tiles

Mine, Reviews, Approvals, Blocked, Budget, Ready and Sessions running — each with its count. Click a tile to jump to its list; empty ones are dimmed.

## Inbox

One feed of things to act on, newest first:

| Item | Comes from |
|---|---|
| approval needed | a pending approval request |
| gate failed | the latest gate run of a task failed |
| task blocked | a blocked task and its reason |
| budget | a task near or over its token budget |
| review requested | a task waiting for a verdict |
| session failed | a headless session that ended with an error |

Click an item to open it; **✓** marks it read, **Mark all read** clears the list. Read marks are stored on your machine only. The bell in the header shows the unread count.

## Queues

Cards appear for queues that hold something — mine, review queue, ready now, approvals, blocked, budget watch, claims and sessions. Empty queues are summed up in one *All clear* line.
