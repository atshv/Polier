### Inferred

- The loaders in use (`load_board(strict=False)`, `runs.load_run`, `approvals.load_all`, `evidence.gate_records`) are read-only and tolerate broken files, so a broken record cannot crash the report. `_unreadable` re-parses JSON only to name such files, which does not amount to a second parser of the record format.
- `--since` keeps undated items (factory items, open questions) and drops old pending approvals. This is consistent with "ignore records dated before this day", but it means an old stalled approval disappears under `--since`.
- The scope-pressure keyword regex will miss phrasings such as "needs file X not in the brief". With the run branch dead, the class may undercount.
