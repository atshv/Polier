### Test hermeticity fix (claude/test/claude.test.mjs:21-23)

The fix is sound. `CLEAN_ENV` removes every `POLIER_*` and `CLAUDE_PLUGIN_OPTION_*` variable, and `env()` sets only `POLIER_PYTHON` and `POLIER_RUNTIME_DIR` again. These are the only prefixes that `configFromEnv` reads (claude/lib/host.mjs:27-32, 96). No Python module under `core/` or `tools/` reads `os.environ`, so the two `spawnSync(PY, …claim.py…)` calls without `env` (lines 210 and 216) cannot leak the setting. No existing assertion was changed; only the env helper was changed.

### Inferred

- Mode `off` is also refused by pl_quick, since its role is not `lead`. The brief only requires refusing a worker or reviewer, and refusing `off` errs on the safe side.
- In Claude Code, session state is keyed per session and subagent (claude/server.mjs:147-150). pl_quick therefore inherits the same lead isolation as pl_state and does not add a new path.
